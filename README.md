# Untoastify Demo

A small React + Vite demo app showcasing the `untoastify` notification library.

## Overview

This project is a lightweight example for displaying toast-style notifications in a browser app. It demonstrates how to trigger different message states, such as success, error, or info notifications, using the `untoastify` package.

## Tech Stack

- React
- Vite
- untoastify

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open the local Vite URL shown in the terminal to view the app.

## Production Build

```bash
npm run build
```

This will create a production-ready bundle in the `dist` folder.

## Preview Build

```bash
npm run preview
```

This serves the production build locally so you can inspect it before deployment.

## Notes

This app is intended as a demo/reference for integrating `untoastify` into a simple React interface. You can use it as a starting point for adding notifications to your own project.
